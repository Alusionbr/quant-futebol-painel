# Painel QUANT Futebol

Este repositório contém somente arquivos estáticos compilados da interface. O código-fonte e a rotina de coleta ficam em um repositório privado. A interface exige login no projeto Supabase QUANT; os dados são protegidos por políticas RLS.

Site: https://alusionbr.github.io/quant-futebol-painel/

O pacote público inclui a URL do projeto e uma chave publishable do Supabase, conforme o uso previsto dessas chaves. Não inclui chaves administrativas, token de ingestão ou dados de partidas.
